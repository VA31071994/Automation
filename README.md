# Learn Automation Project

This repository contains learning materials and automation scripts for Java and JavaScript.

## Project Structure

- **01.Chapter_01_Basics**: Introduction to basic concepts.
- **02.Chapter_02_JavaBasics**: Java programming fundamentals and automation basics.

## Getting Started

### Prerequisites
- Java JDK 11 or higher
- Node.js (for JavaScript scripts)
- Git

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/VA31071994/Automation.git
   ```
2. Navigate to the project directory:
   ```bash
   cd LearnAutomation
   ```

## Usage
Explore the chapters sequentially to follow the learning path. Each directory contains specific exercises and examples.
